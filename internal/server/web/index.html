File integrity watchlist

        
One path per line (files or directories, max 100). Agents in this org hash watched files and raise fim_change events on any modification. Applied at the agents' next config poll (≤5 min).

        
        
      

      
Alert routing

        
Where this org's alerts go, on top of the collector's global webhook/Slack/email. Each route fires for alerts at or above its severity. PagerDuty/Opsgenie use the integration/API key as the target; firing→trigger, resolved→resolve.
